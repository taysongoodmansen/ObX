# Design Desisions

<details>
  <summary>Coding in C</summary>

I decided to code everything from scratch in C.
I did that because C is good performance language, and links Myx into Wayland better, and to have both things built in the same language allows better connection.

I also decided that everything will be coded entirely from scratch, because it allows better control, understanding, and future customizability for users.

</details>
