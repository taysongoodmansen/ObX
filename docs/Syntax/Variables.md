Variables and Variables setting is very similar to Python in how they work.

Variables can be set without declaring their types. They can also change
types throughout the program.

The types are also similar to Python.
Intergers - Whole numbers ex: 3, 7, 207
Floats - Numbers with decimal points ex: 2.7, 19.20, 0.3
Strings - Words and letters ex: "hello", "jerry", "he is 513"
Booleans - True or False
Collections - Multiple variables stored under on variable. Pythons lists 
    and dictionaries in one. Use keys and values for everything, but
    if no keys given it will defualt to indexed keys, so `["a","b","c"]`
    will set the keys as 0, 1, and 2 (indexs start at 0). And to
    specify keys you would do `["name":"bob","age":13,","employed":True]`
    They can also be combined but unrecomended to do if setting
    in whole like `[1,7,34,"Title":"employee]`.
    Any value inside can be accessed doing variable[key] where indexed
    ones are just their number.
Events (currently unsupported) - Used to dynamically connect one
    peice of code to another. Very useful to make code that wont run
    during start up of the window manager, but wait until something 
    later to run.
